The Repo includes the Jupyter notebook of the project. 
The zip files are all of the files in the dataset. train_1 and train_2 are the training photos set. val is the validation photos set. Test photos are in Testphotos.zip. 
The labels contain both the training and validation set labels.
The yaml file contains the classes and paths for the YOLO trainer.
